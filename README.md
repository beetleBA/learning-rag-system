# RAG-библиотека

## Используемые технологии

- **Python** - основной язык разработки.
- **PyMuPDF** - извлечение текста из PDF-документов с сохранением Markdown-структуры.
- **LangChain Text Splitters** - разделение текста на чанки.
- **Sentence Transformers** (`multilingual-e5-small`) - преобразование текста в векторные представления (эмбеддинги).
- **Qdrant** - векторная база данных.
- **GigaChat** - генерация ответов (структурированный JSON-вывод).
- **Pydantic** - проверка структуры и типов данных ответа.
- **python-dotenv** - загрузка конфигурации.

## Как работает библиотека

1. **Загрузка документов.** Из PDF извлекается текст с сохранением структуры.
2. **Разбиение на чанки.** Текст разделяется на фрагменты с перекрытием для сохранения контекста.
3. **Векторизация.** Каждый фрагмент преобразуется в эмбеддинг с помощью `multilingual-e5-small`.
4. **Индексация.** Векторы и метаданные сохраняются в Qdrant.
5. **Поиск.** Вопрос пользователя преобразуется в вектор, после чего Qdrant находит наиболее близкие по смыслу фрагменты.
6. **Генерация ответа.** GigaChat получает вопрос и найденный контекст, формирует ответ в Markdown и возвращает его в структурированном JSON.
7. **Формирование источников.** Python сопоставляет идентификаторы контекста (`CTX-1`, `CTX-2` и т. д.) с реальными документами и формирует список источников.

## Формат ответа

Библиотека возвращает JSON с полями:

- `answer_markdown` - ответ в формате Markdown.
- `sources` - список использованных источников с указанием документа, страницы, фрагмента и оценки релевантности.
- `insufficient_information` - признак недостаточности информации для ответа.

**Основной принцип:** GigaChat формирует ответ на основе найденных документов, а Python отвечает за поиск, проверку идентификаторов и формирование списка источников.
